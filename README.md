# PDF Guru

PDF Guru is a free online PDF toolkit. Convert photos to PDF, merge and split documents, generate GST invoices, and summarize PDFs in the browser.

## Tools

- Photo to PDF
- Merge PDF
- Split PDF
- GST Invoice Generator
- AI PDF Summary (mock service, ready for a real model)

## Stack

Next.js 14, TypeScript, Tailwind CSS, shadcn/ui, pdf-lib, jsPDF.

Phase 1 processing is client-side. Files are not stored permanently.
